# Locus extension gallery service

This read-only service scans already signed `.locusx` packages, fails startup if
any package is invalid or untrusted, serves immutable SHA-256-addressed downloads,
and publishes Ed25519-signed catalog and revocation documents. The desktop still
verifies every package and security document independently.

```bash
LOCUS_GALLERY_PACKAGES=/absolute/path/to/packages pnpm --filter @locus/extension-gallery-service dev
```

Production mode requires metadata generated by the offline publication command:

```bash
LOCUS_GALLERY_PACKAGES=/reviewed/packages \
LOCUS_GALLERY_METADATA=/publication/metadata \
LOCUS_GALLERY_SIGNING_KEY_FILE=/offline/gallery-ed25519.pem \
pnpm --filter @locus/extension-gallery-service publish
```

`deploy/gallery/compose.production.yaml` is the hardened container baseline.
The current built-in trust key remains canary-only; complete the production key
ceremony, publisher/malware review process, domain deployment, and external
security review before public access.
